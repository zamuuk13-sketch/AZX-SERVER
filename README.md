# AZX Server

Gerenciador local de servidores Minecraft para Windows.

## Requisitos
- Windows 10/11 64-bit
- Java 17 para Minecraft 1.20.1
- Internet durante a instalação

## Começar
1. Baixe ou clone este repositório e extraia a pasta.
2. Execute AZX-SERVER.bat.
3. Escolha Criar novo servidor e siga as perguntas.
4. A instância será criada em servers/NOME_DO_SERVIDOR.
5. Leia o EULA em eula.txt. Altere eula=false para eula=true somente se concordar.
6. Execute start.bat.

Coloque os mods .jar compatíveis na pasta mods da instância. Para acesso externo, configure encaminhamento TCP da porta 25565 no roteador. CGNAT pode impedir conexões diretas. Desativar online-mode permite conexões sem autenticação oficial e aumenta riscos de falsificação de identidade; use somente em servidor privado com pessoas confiáveis.

O AZX Server não distribui Minecraft, Java ou mods. O EULA não é aceito automaticamente.
